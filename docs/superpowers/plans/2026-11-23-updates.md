# Automatic releases and Debian installer

Use only stable releases from Nolfad/open-audio-bridge, numeric version ordering, bounded HTTPS downloads, SHA256 integrity and safe ZIP extraction. Scheduled checks every six hours, retry pending updates every fifteen minutes when playback is idle. Manual update is explicit and can interrupt playback. Preserve presets, volume, enabled state and update preference; keep existing transactional backups/rollback. Single updater lock, installer lock, no downgrade after a race with another installer. No root for runtime updates.

Systemd user timer persists independently of the GUI. GUI exposes status, opt-out, update-now and reloads idle after installed version changes without losing tray. Installer .deb supplies dependency metadata and bootstrap sources, clearly distinguished from a distribution-managed runtime or APT repository. Flatpak submission deferred because current host integration needs architectural work.

Validation: local fake release fixtures and rejection paths; .deb extract/metadata/launcher tests; packaged build; real user installation and scheduled no-update check against GitHub. Integration simulations must be labeled separately from a future real version upgrade.
